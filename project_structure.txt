Fire Clash BD — Project Structure
=================================

.
├── icon.png                # App icon / Esports branding logo asset
├── index.html              # Main HTML container & Document title
├── metadata.json           # AI Studio project information & environment roles
├── package.json            # Project dependencies list & executable scripts
├── tsconfig.json           # TypeScript compilation settings
├── vite.config.ts          # Vite build configuration structure
├── .gitignore              # Files to exclude from version control
└── src/                    # Source code root directory
    ├── main.tsx            # App bootstrap entry point file
    ├── App.tsx             # Primary visual application container
    ├── data.ts             # App specifications pool (APK size, download links, active stats)
    ├── index.css           # Global stylesheet containing custom font imports and theme overrides
    ├── vite-env.d.ts       # Developer compiler environment references
    └── assets/             # Raw media assets dictionary
        └── images/         # Storage for raster illustrations or logo files (empty)
